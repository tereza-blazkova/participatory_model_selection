# Workshop instruments

The materials used in the workshop, with institution-specific names removed and the
plan's wording lightly edited. The specification participants assessed is not reproduced.
The plan's timings are as planned; the workshop itself took three hours, including breaks.

| File | What it is | Framework stage |
|---|---|---|
| `baseline_endline_survey.pdf` | The survey participants completed before and after deliberation | Stage 3 |
| `acceptability_assessment.pdf` | The assessment of the resulting specification | Stage 3f |
| `workshop_plan.pdf` | The plan of events | Stage 3 |

To reuse them, replace the data sources and explainability levels with the ones
your institution is actually considering. The survey's response scale is what
becomes the selection rules: see `ADAPTING.md`.
